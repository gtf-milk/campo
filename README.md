# Caderno de Campo GTF Milk

Aplicativo de campo da GTF Milk (Lebon Régis/SC): rotação das novilhas nos piquetes, avaliação do pasto, tratamentos, aplicações e carência.

- Endereço: https://gtf-milk.github.io/campo/
- Funciona instalado no celular (Android pelo Chrome, iPhone pelo Safari) e sem internet no campo.
- Os registros ficam no Firebase (projeto gtf-milk-campo), protegidos por login. Este repositório guarda só o aplicativo.
